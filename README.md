# garimpo

Notícias diárias de tecnologia, em português, reunidas de agregadores públicos do GitHub.

Todo dia de manhã uma rotina lê o que as fontes publicaram, traduz e resume. Em [`data/`](data) cada arquivo é um tipo de conteúdo (`arxiv.json`, `hackernews.json`, `producthunt.json` e por aí) com tudo o que já saiu, do dia mais recente para trás. O [`rss.xml`](rss.xml) na raiz junta todas as categorias num feed só.
