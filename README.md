# radar

Notícias diárias de tecnologia, em português, reunidas de agregadores públicos do GitHub.

Todo dia de manhã uma rotina lê o que as fontes publicaram, traduz e resume. Em [`data/`](data) cada pasta é um tipo de conteúdo (Arxiv, HackerNews, ProductHunt, Twitter e por aí), e cada dia vira um arquivo em Markdown para ler e outro em JSON para consultar.

## Fontes e direitos

Quando a licença da fonte permite, o conteúdo é traduzido e republicado aqui com atribuição e link para o original. Quando não permite, fica só o ponteiro para o arquivo original.

Os direitos das matérias são de seus veículos. Este repositório reúne referências, links e resumos, e não substitui a leitura na fonte.
